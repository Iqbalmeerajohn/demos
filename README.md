# Concept previews

Website concepts I design for local businesses before pitching them. Each page is clearly labelled as a concept preview, is not the business's official website, uses only public information about the business and CC0 sample photos, and is marked `noindex` so it never appears in search results. A preview is removed on request or if the business isn't interested.
